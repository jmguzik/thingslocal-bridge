# Changelog

## 0.2.0 — Experimental public release

Continued work on **LocalThings by purplesym (Lars)** and the LocalThings
contributors, using the unmodified upstream MQTT implementation.

- Multi-appliance STDK MQTT monitoring with separate identities and durable registration.
- Cooktop and dishwasher profiles, read-only by default.
- Opt-in dishwasher program selection without starting a washing cycle.
- Dishwasher attention/cleaning sensors and a reusable notification blueprint.
- Private setup/runtime separation, recovery instructions and certificate expiry diagnostics.

Your own domain and compatible TLS certificate are required. RapidSSL was tested.
See the repository README and UPSTREAM.md for setup, evidence and source attribution.
